# Создание ролей
**Роли** - блоки, содержащие в себе таски, переменные, шаблоны для выполнения конкретных задач.

Файловая структура:
```
role_name/
├-- defaults/
	├-- main.yml
├-- handlers/
	├-- main.yml
├-- tasks/
	├-- task_name.yml
├-- templates/
	├-- faillock.j2
	├-- faillock_notify.j2
```
Назначение директорий:
- `defaults/main.yml` - позволяет включать/отключать часть правил в роли;
- `handlers/main.yml` - содержит отложенные задачи, которые выполняются тогда, когда на них ссылаются с помощью ключевого слова `notify`;
- `tasks/task_name.yml` - основной файл для тасок;
- `templates/...` - шаблоны jinja2 формата.
