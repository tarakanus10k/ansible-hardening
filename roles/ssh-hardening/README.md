# Роль: ssh-hardening

**Secure Shell (SSH)** - это сетевой протокол прикладного уровня, который позволяет управлять компьютерами и серверами удаленно через защищенный канал связи. Это безопасная зашифрованная альтернатива распространенным протоколам для входа в систему, таким как telnet, ftp, rlogin, rsh и rcp.

файловая структура роли:
```
ssh-hardening/
├-- defaults/
	├-- main.yml
├-- handlers/
	├-- main.yml
├-- tasks/
	├-- ssh.yml
```

Реализованные правила:
1. *5.1.1 Убедитесь, что настроен доступ к /etc/ssh/sshd_config*
	- `sshd_config` - конфигурация sshd, которая определяет, кто и как может войти. Если не настроить права, то непривилегированный пользователь сможет поменять настройки sshd, что может позволить атакующему получить доступ к серверу или вовсе сломать удаленный доступ к серверу по ssh.
2. *5.1.2 Обеспечьте настройку доступа к каталогу /etc/ssh/sshd_config.d/*
	- `sshd_config.d` - директория, содержащая дополнительные настройки для ssh. Если не настроить права, то непривилегированный пользователь сможет добавить новые настройки или изменить уже существующие, что может позволить атакующему получить доступ к серверу или вовсе сломать удаленный доступ к серверу по ssh.
3. *5.1.15 Убедитесь, что для sshd настроено LoginGraceTime*
	- `LoginGraceTime` - отвечает за время неаутентифицированного соединения. Сокращение времени на аунтификацию позволит уменьшить окно медленного перебора паролей/ключей для доступа к серверу.
4. *5.1.18 Убедитесь, что параметр sshd MaxAuthTries настроен*
	- `MaxAuthTries` - отвечает количество попыток аутентификации в рамках соединения. Также позволяет снизить скорость перебора паролей/ключей для доступа к серверу.
5. *5.1.21 Убедитесь, что параметр sshd PermitEmptyPasswords отключен*
	- `PermitEmptyPasswords` - позволяет запретить вход в учетную запись, у которой отсутствует пароль.
6. *5.1.22 Убедитесь, что параметр sshd PermitRootLogin отключен*
	- `PermitRootLogin` - позволяет отключить вход по ssh от root-пользователя.
7. *5.1.24 Убедитесь, что для sshd UsePAM включено значение true*
	- `UsePAM` - позволяет привязать sshd к pam, что дает возможность использовать pam-модули для увеличения защищенности ssh.
