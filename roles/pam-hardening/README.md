# Роль: pam-hardening

**Pluggable Authentication Modules (PAM)** - служба, которая реализует модульные
модули аутентификации в системах Linux. PAM реализован в виде набора разделяемых объектов, которые загружаются и выполняются, когда программе требуется аутентифицировать пользователя.

файловая структура роли:
```
pam-hardening/
├-- defaults/
	├-- main.yml
├-- handlers/
	├-- main.yml
├-- tasks/
	├-- pam.yml
├-- templates/
	├-- 50-identity.rules.j2
```

Реализованные правила:
1. *5.3.1.1 Убедитесь, что установлена последняя версия pam*
	- Модули подключаемой аутентификации - набор библиотек, которые позволяют системному администратору Linux настраивать методы аутентификации пользователей.  Они обеспечивают гибкий и централизованный способ переключения методов аутентификации для защищенных приложений с помощью файлов конфигурации, а не изменения кода приложения.
2. 5.3.2.2 Убедитесь, что модуль pam_faillock включен
	- Данный модуль позволяет ввести список неудачных попыток аутентификации для каждого пользователя за определенный промежуток времени и блокирует учетную запись, если количество неудачных попыток аутентификации подряд превысило заданное значение. Если данный модуль будет отключен, то неудачные попытки входа никак не будут ограничены.
3. *5.3.3.1.1 Убедитесь, что настроена блокировка после неудачных попыток ввода пароля*
	- Позволяет ограничить количество неудачных попыток аутентификации подряд.
